Perchling 2.0 beta

Perchling 2.0 is a rebuild of YouTube Playlist Tools. Betas are numbered 1.99.1, 1.99.2 and so on, and each one updates to the next by itself.

Firefox

No beta build is out yet.

  1. Open the download link in Firefox 140 or later.
  2. Firefox asks whether to add Perchling for YouTube™. Click Add.
  3. If you have YouTube Playlist Tools 1.4.5, Firefox installs the beta as its update. Your playlists, shortcut, watch percentage and toast setting carry over, and nothing runs until you've reviewed them on the page that opens.
  4. Later betas install by themselves. Once 2.0.0 is out on Firefox Add-ons, the last beta update moves you to it, and from then on Firefox Add-ons updates it.

Chrome

The Chrome beta is an unlisted item on the Chrome Web Store, for Chrome 121 or later. Its link appears here once the store has approved the first beta.

Problems and ideas

Open an issue on GitHub, which needs a GitHub account. Settings › Diagnostics has a report you can paste into it. The report names no video, playlist, channel or account.

The beta follows the same privacy policy as the release.
