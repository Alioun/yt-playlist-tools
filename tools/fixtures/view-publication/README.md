# Publication authoring fixture

This fixture uses the real canonical owner, Tabs, AddFlow, Monitor and complete TabView producer. Native tabs, storage, clock, visibility and health facts are synthetic. It seeds two normal cores and one private core for account A, plus normal and private cores for account B. No production adapter or entry is activated.

All runtime checks below are **unexecuted**. This authoring unit never held the product runtime lease. The exact917 input retains accepted verification repairs and native starting-owner paths. The coordinator must provide verified prepared dependencies before granting a future lease. Local dependency availability and executable identities are recorded under `.audit/private-skip-publication-authoring/dependencies.json`; an available host binary is not accepted qualification evidence.

`expected.jsonl` contains the entire authored consumer output, including every complete view and final cleanup counts. It is 10,217 bytes through the final LF, with SHA-256 `1dad7b34e309cf03df5b8e0c998e92b29dc18c4acb44b3ed3975835dcf34989f`. Account A's Filter change sends to IDs 1, 2 and 9 at 250 ms. Pause then sends to IDs 1, 2, 3, 9 and 10 at 500 ms. Private skip and unskip publish only to ID 9 at 750 and 1250 ms. The intervening equal edit publishes nothing. A normal AddFlow skip publishes only to IDs 1 and 2 at 1500 ms. The sorted native targets are `[1,1,1,2,2,2,3,9,9,9,9,10]`. Cleanup expects zero publisher subscriptions and zero open deadlines. The independent Python construction in `.audit/private-skip-publication-authoring/author-metadata.py` derives every field and timeline entry without loading the expected file or product modules. These bytes were authored from source, not observed from execution.

`future-gates.json` is the complete command inventory. Run commands from the reconciled source root under the coordinator's sole runtime lease. Use prepared dependencies only, a cleared child environment, scratch HOME and TMPDIR, and Bun's `--no-env-file --no-install` flags. Do not run the ambient Bun 1.2.8 recorded in the local availability report: the source requests Bun 1.4.3. Verify exact prepared binary and declaration identities before any gate. Each listed command has a deadline; code 124 is a timeout, never a pass. Reap each owned child.

Every exact command uses pinned executables, a pinned PATH, closed stdin and a bounded timeout. `execution-pins.json` records static hashes. `qualification.py` applies the same environment and Bun flags to fixture descendants. No qualification launcher ran. Prepared local node_modules and WXT declarations are absent.

The first compiler gate includes the union of frozen Monitor, Tabs, complete TabView and playlist-cache roots plus this fixture's roots. The separate ExtLink compiler gate preserves that fixture's own roots. There are no new exclusions. A failing baseline blocks mutation and intended-line credit. The new tests cover owner readback, real sync adoption/join, targeting, removal without registry resurrection, shared changes, normal skips, 249/250 ms overlap, projection/send races, fresh account/privacy/build checks, Monitor comparisons and disposal. Protected runtime regressions retain their original assertions, including the unknown-collection proof.

`type-probes.json` records 19 negatives with their exact directive and diagnostic lines. Each bounded future command removes one directive without changing line numbers, requires a diagnostic only on its intended path/line, restores original bytes and mode, and requires a restored compiler pass. Existing type negatives remain in the compiler roots.

`controls.json` and `controls/*.patch` give twelve exact mutation proposals. For each, the future runner requires baseline compilation and the named passing test, mutant compilation, a failure of that named behavioral test, exact byte/mode restoration, and restored compilation and test success. A compiler error supplies no behavioral credit. The `observableAssertion` field names the assertion each mutation should break. The four added controls cover normal-tab broadcast, omission of an internal automatic event, notification before a successful fresh load, and a private deadline surviving disposal. Mutant compilation is unexecuted. Mutation execution remains unauthorized until the coordinator grants a lease.
