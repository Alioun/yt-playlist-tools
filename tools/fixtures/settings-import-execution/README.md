Settings import execution authoring
==================================

This fixture drives the canonical local owner with the actual file parser and existing import planner. It has not been compiled or executed. Product behavior remains unqualified.

The consumer imports A, B, D, E and F, preserves C, empties B and D, retains F through its kept filter and compares the complete local, session and sync records. Its two independently written JSONL rows cover sync off and sync on. The call assertions require one complete document batch, one stamp per admitted document, no remote reads with sync off, complete cleanup and publication after terminal readback.

The owner cases cover refusal, whole-batch quota admission, stale captures, write rejection with and without effect, ignored and mismatched writes, restart around every mutation, withdrawal, a later Agree, exact one-use recovery, read barriers, retirement and disposal. The canonical fixture uses the accepted retained-authority construction APIs. The publication fixture uses real Tabs, TabView producer and publication services with finite native collaborators.

`controls.json` names nine isolated mutation patches and their observable assertions. Each patch was applied statically with zero fuzz and zero offset. Compiling status, baseline, named red and restored pass are all unexecuted. Static replay proves bytes and modes only.

`type-probes.json` pins every new directive and intended diagnostic line. `upstream-type-line-relocations.json` relocates inherited probes without modifying their protected inventories. `preserved-inventories.json` records the identities of all 88 upstream fixture files in the four required groups.

`future-gates.json` contains exact future argv arrays. Each Bun invocation includes `--no-env-file --no-install`, a cleared environment, pinned executable, scratch HOME/TMPDIR, closed stdin and a deadline. The later qualifier must enforce the same policy for descendants and obtain its own runtime lease. The manifest is not a launcher and grants no execution authority. Dependency bindings and generated declarations must be established separately from their recorded identities. Both consumer outputs must match the expectation through EOF and then match each other.

Native, privacy, rendering/axe, all three picker policies and activation remain held. No real import cleanup host is assembled by the native facade. Upstream owner-services and publication runtime qualification remains outstanding. This work does not complete 2.0.
