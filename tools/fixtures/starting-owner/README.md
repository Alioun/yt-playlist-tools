The consumer records pending readiness, held startup, one confirmed first-run choice, canonical Setup access, session persistence, duplicate-owner refusal, and teardown. It has no result adapter or alternate owner.

All commands remain unexecuted. Cache qualification holds the runtime lease. A later executor needs that lease before any compiler, test, fixture, or product execution. Native guarantees, privacy approval, activation, and the three picker decisions remain held.

1. Reconcile accepted Accounts, cache, auto-add, and Monitor owner repairs into the frozen source before qualification. Rehash every changed dependency.

3. Use the exact commands in `.audit/starting-owner-authoring/future-gates.json`. Every command clears the inherited environment, uses scratch HOME and TMPDIR, pins executable paths, and has `timeout -k 10 540`. The qualification script runs each product child under its own 45-second deadline and records its direct wait and immediate owned-group status. The record makes no complete descendant-enumeration claim.
4. Run `prepare` first. It creates local links to individual prepared packages and copies pinned generated WXT declarations. It does not execute package scripts or install packages. Inspect and repair any unsafe launcher before executing product code.
5. Run the whole-source compiler, inclusion, focused behavior, architecture, real consumer, and adjacent regression commands. The qualification tsconfig includes all repository source, tests, fixtures, scripts, build helpers, and root TypeScript files. It adds no exclusion and preserves the root and WXT configurations. Inclusion checks every candidate TypeScript path.
6. Run each of the intended-line type negatives separately. The script replaces one directive with a blank line, requires diagnostics on the recorded next line, restores exact bytes and mode, and requires clean restored compilation.
7. Run each of the five controls separately. Require baseline compilation and behavior, then mutant compilation, then the named failed observable assertion. Restore exact source bytes and modes. Require restored compilation and behavior. `controls.json` contains proposals, not compiling results.

Every direct Bun invocation includes `--no-env-file --no-install`. The scratch PATH also supplies a Bun launcher with both flags for descendants that resolve Bun through PATH. These gates do not call the repository's Bun suite launcher. A descendant that launches an absolute Bun path still needs both flags verified before execution.

The fixture output is one compact dummy-data JSON record. A timeout, missing dependency, compiler failure, missing intended diagnostic, unrelated exception, or surviving owned process group is a failed gate. Report the command and its last output. Do not rerun an unchanged timeout.

The source archive, patch replay, mode verification, and independent rehash from authoring establish source identity only. Runtime behavior remains unqualified. This adapter does not establish native ownership, durability, credential isolation, approved privacy wording, or complete 2.0.
