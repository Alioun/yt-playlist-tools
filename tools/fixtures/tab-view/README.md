# Complete TabView consumer

This authored fixture connects the actual account projection, AddFlow private memory, full TabView producer, Tabs hello receiver, native callback adapter, serialized memory RPC, PageLink and ExtLink. It supplies `isTabView` to both ends. It supplies synthetic health and synthetic native facts. It establishes no real Monitor or native-browser guarantee.

The four cases cover signed-in YouTube, private YouTube, YouTube Music and signed-out YouTube. Each returns its complete initial and pushed view, ping, push result, publication observations, normal skip preservation, session registry count, message kinds and cleanup counts. Shared Pause uses the actual AddFlow and owner. Private skips use the actual AddFlow memory and do not enter normal skips.

`expected.jsonl` is a manually authored expectation. It has one LF followed by EOF. `expected-bytes.json` records its size and SHA-256. No consumer output has been captured in this authoring unit.

The production constructor requires status and notice producers. Each available result binds the current tab, window, account, site, build and privacy. Its synchronous `current()` check must remain valid through composition. Missing collaborators, unavailable facts, revoked generations and invalid views return `unavailable`. The synthetic helpers here cannot be used in production composition.

`controls.json` contains six exact proposed compiling mutations and each behavior assertion they must break. `type-probes.json` records intended diagnostic lines. `qualify.py` requires a separately granted runtime lease. It requires clean compilation, baseline behavior, compiling mutations, failing behavior, exact restoration and restored passing gates. Every compiler, test, consumer, control and type-negative gate is unexecuted.

Use the prepared dependencies recorded by the audit. Do not install packages or regenerate WXT during authoring. Reconcile the concurrent ExtLink/Tabs runtime return before qualification. ARC-MSG-13 publication filtering and coalescing belong to later composition. This fixture adds no publication subscription or timer.
